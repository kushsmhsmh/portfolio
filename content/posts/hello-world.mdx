This is a starter post. Every post on this site is a single Markdown file, so
adding a new one takes about ten seconds.

## Adding a post

Create a new file in `content/posts/` ending in `.mdx`, for example
`content/posts/my-new-post.mdx`, and give it a frontmatter block:

```md
---
title: "My new post"
date: "2026-09-20"
summary: "One line shown in the list and previews."
tags: ["idea"]
---

Write your post here in Markdown.
```

That's it. The post shows up automatically, sorted by `date` (newest first).

## What you can write

Regular Markdown works — **bold**, *italics*, [links](https://example.com),
lists, quotes, and fenced code blocks with syntax highlighting:

```ts
function greet(name: string) {
  return `Hello, ${name}`;
}
```

Delete this file whenever you're ready to make it your own.
